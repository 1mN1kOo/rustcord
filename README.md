### Производительность

| Параметр | Оригинал | Rustcord |
|---|---|---|
| **Фоновые процессы** | 6+ процессов | 1 процесс |
| **Память (RAM)** | 3.6% (~600–1100 МБ) | 0.1% (~30–90 МБ) |
| **Нагрузка на CPU** | 4.2% в простое | 0% |
| **Время запуска** | 5 – 10 секунд | ~300 миллисекунд |
| **Вес клиента** | 150+ МБ | 5.4 МБ |
| **Фоновые трекеры** | Активны | Заблокированы |

### Возможности

- **Полная функциональность:** Серверы, личные сообщения, голосовые каналы, видеозвонки и демонстрация экрана с живыми превью окон (DWM).
- **Чистый трафик:** Встроенный перехватчик сетевых запросов блокирует аналитику и телеметрию.
- **Интеграция с Windows:** Системный трей, сворачивание в фоновый режим, горячие клавиши, Single Instance.
- **Автообновления:** Бесшовные фоновые обновления через официальный сайт.
