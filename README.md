### Возможности

- **Полная функциональность:** Серверы, личные сообщения, голосовые каналы, видеозвонки и демонстрация экрана.
- **Чистый трафик:** Встроенный перехватчик сетевых запросов блокирует аналитику и телеметрию.
- **Тёмный запуск:** Окно открывается сразу в тёмных тонах без засвета экрана.
- **Интеграция с Windows:** Системный трей, сворачивание в фоновый режим, горячие клавиши.
