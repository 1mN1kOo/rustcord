## 🚀 Основные фичи

- **Официальный Discord:** Поддерживает все официальные функции: серверы, личные сообщения, голосовые каналы, видеозвонки и демонстрацию экрана.
- **Chrome User-Agent Spoofing:** Обходит проверку Discord на браузер, открывая полный доступ к WebRTC звонкам.
- **Zero White Flashbang:** Окно открывается сразу в тёмной теме без раздражающей белой вспышки загрузки.
- **Блокировка телеметрии:** Вшитый `inject.js` перехватывает сетевые запросы к аналитическим сервисам Discord, убирая микрофризы.
- **Интеграция с треем Windows:** Сворачивание при закрытии `[X]` в системный трей, контекстное меню быстрого доступа.
- **Аппаратное ускорение:** Включены флаги GPU-растеризации и прямого видео-декодирования.
